# Contributing

Thanks for your interest in improving AccessCheck Universal.

## Before opening a pull request

1. Create a focused change and explain the problem it solves.
2. Run `npm test`.
3. Test the UI locally with `npm start` where applicable.
4. Do not weaken URL validation or network restrictions without a clear security analysis.
5. Do not include scan reports containing private, authenticated, or sensitive page content.
6. Update the README when setup, behavior, or limitations change.

Please report security issues privately to the repository owner rather than publishing exploit details in a public issue.
