# Security Policy

AccessCheck Universal is intended for local learning and portfolio use. It is not a hardened hosted scanning service.

## Safe use

- Keep the service bound to `127.0.0.1`.
- Scan only public websites you are authorized to test.
- Do not expose the server to the public internet or use it as a multi-user service.
- Do not enter credentials or scan authenticated pages.
- URL/DNS checks reduce risk but cannot eliminate every DNS-rebinding, browser, or network edge case.

If you believe you found a security issue in this project, contact the repository maintainer privately with a concise description and reproduction steps. Avoid including sensitive data.
